Databases

Talking to a database directly: drivers, pools, transactions, migrations, and the operational details that decide whether it survives production.

14 pages

  • Choosing a databaseAn honest decision framework for picking Postgres, MySQL, SQLite, MongoDB or Redis for a Node.js backend, and what each one actually costs you.
  • PostgreSQL with pgUsing the pg 8.23.0 driver directly — pools, client checkout, type parsers, timeouts, upserts, JSONB and SSL for managed providers.
  • MySQL with mysql2Using mysql2 3.24.4 with promises — pools, execute versus query, the prepared-statement cache, type coercion options and why multipleStatements must stay off.
  • SQLiteUsing node:sqlite and better-sqlite3 13.0.3 from Node 24, with WAL mode, foreign keys, busy timeouts and the single-writer model that decides where SQLite belongs.
  • MongoDBUsing the mongodb 7.6.0 driver directly — client reuse, pool sizing, indexes, cursors, aggregation, replica-set transactions and the operator-injection auth bypass.
  • RedisUsing node-redis 6.2.1 or ioredis 6.0.0 for caching, rate limiting and pub/sub, with TTLs, stampede protection, SCAN instead of KEYS, and an honest account of durability.
  • Connection poolingWhat a database pool actually does, how to size it, how to spot exhaustion and leaks, and why serverless plus Postgres needs PgBouncer or RDS Proxy.
  • TransactionsCorrect BEGIN/COMMIT/ROLLBACK patterns in pg and mysql2, a reusable withTransaction helper, isolation levels, row locking, and retrying deadlocks and serialization failures.
  • MigrationsVersioned, forward-only schema changes run in CI, with expand/contract for zero downtime, CREATE INDEX CONCURRENTLY, lock_timeout, and a separate DDL credential.
  • SeedingIdempotent seeds with upserts, separating reference data from demo data, deterministic fake data, per-test strategies, and why test accounts must never reach production.
  • Health checksDatabase health probes that do not cause cascading restarts — liveness versus readiness, a cheap SELECT 1 with a hard timeout, cached results, and safe dependency reporting.
  • Retries and timeoutsBounding database work at every layer with AbortSignal.timeout, retrying only the errors that are retryable, exponential backoff with full jitter, idempotency keys and circuit breaking.
  • N+1 queriesWhat an N+1 costs in real numbers, three ways to fix it with a JOIN, a batched ANY query or DataLoader-style batching, how to detect it, and when it is actually fine.
  • Indexing basicsB-tree fundamentals, composite column order and the leftmost-prefix rule, covering and partial indexes, reading EXPLAIN ANALYZE, write cost, and finding unused and missing indexes.
